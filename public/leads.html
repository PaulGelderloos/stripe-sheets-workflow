How these numbers are made
Population
HubSpot contacts created inside the period with record source = Form, read live each time you run the report.
Channel
Derived from leadsource_code. GAP is Google Ads paid spend; Grant traffic is reported separately under Other, alongside WhatsApp, email, referral and local centre promotion.
No code
Leads carrying no campaign code. Before 25 August 2026 the website discarded these on most pages, so anything earlier sits here and cannot be recovered.
Lead type
An intro talk booking has lezing_datum_iso set. Everything else counts as an enquiry, including course bookings made without a talk.
Centre
centrum_naam from the form, with spelling variants merged.
End date
Inclusive — the whole of the end day counts.
